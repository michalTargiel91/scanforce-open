# Getting help

ScanForce Open is a young open-source project maintained by a small team.
There is no paid support for the open-source app itself. Please use these
channels so that answers help the next person too:

| You want to | Go to |
|---|---|
| Fix a setup problem yourself | [Troubleshooting](docs/troubleshooting.md) and the [quickstart](docs/quickstart.md) |
| Ask a setup or usage question | [Discussions → Q&A](https://github.com/michalTargiel91/scanforce-open/discussions/categories/q-a) |
| Discuss or share a custom provider | [Discussions → Show and tell](https://github.com/michalTargiel91/scanforce-open/discussions/categories/show-and-tell), or the **Provider compatibility** issue template for protocol questions |
| Suggest a feature | [Discussions → Ideas](https://github.com/michalTargiel91/scanforce-open/discussions/categories/ideas) or a feature request issue |
| Report a bug or installation failure | [New issue](https://github.com/michalTargiel91/scanforce-open/issues/new/choose) |
| Report a vulnerability | Privately, as described in [SECURITY.md](SECURITY.md). Never in a public issue. |
| Get help with DocSolved.ai (connector key requests, quotas, billing, review screens) | [hello@synairo.com](mailto:hello@synairo.com) for connector keys ([how to ask](docs/provider-docsolved.md#1-get-a-docsolvedai-connector-key)); otherwise DocSolved.ai's own support channels, listed at [docsolved.ai](https://docsolved.ai) |

## What to include

* ScanForce Open version or commit, and your Salesforce release.
* Provider type: DocSolved.ai or custom. A provider name is enough; no URL is needed.
* The job **Status** and **Error code**, or the **Test connection** message.
* What you did, what you expected, what happened.

## Never include

API keys or tokens, customer documents, extracted values, org IDs,
usernames, session IDs, or debug logs that contain any of these. Redact them
before posting. If you posted one by mistake, revoke it immediately; editing
the post does not remove it from history.
